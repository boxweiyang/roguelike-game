# 深渊撤离区 - 完整开发总结 (12小时优化版)

## 游戏概述
**名称**: 深渊撤离区 v4.0
**类型**: Vampire Survivors风格 Roguelike 提取射击游戏
**技术栈**: HTML5 Canvas + JavaScript + CSS3
**总代码量**: ~130KB game.js + 12KB config.js + 25KB HTML

## 技能进化系统详细设计

### 研究来源
- Vampire Survivors (武器进化系统)
- Brotato (商店与天赋系统)
- 20 Minutes Till Dawn (技能升级)
- Survivors.io (装备进化)

### 进化规则
1. 每个技能有3个进化等级
2. 进化后伤害、范围、投射物数量提升
3. 额外进化效果 (穿透、爆炸、多重等)
4. 进化通过升级卡牌选择

### 8个技能进化树

**斩击 (Slash)**
- Lv1: 基础斩击 (2.5范围, 18伤害)
- Lv2: 强化斩击 (3.0范围, 24伤害, +33%伤害)
- Lv3: 终极斩击 (3.5范围, 32伤害, +78%伤害, 穿透)

**旋风斩 (Whirlwind)**
- Lv1: 基础旋风 (3.5范围, 12伤害)
- Lv2: 强化旋风 (4.0范围, 16伤害, +33%伤害)
- Lv3: 终极旋风 (4.5范围, 22伤害, +83%伤害, 击退)

**手枪 (Pistol)**
- Lv1: 基础手枪 (1投射物, 15伤害)
- Lv2: 双发手枪 (2投射物, 18伤害, +20%伤害)
- Lv3: 四发手枪 (4投射物, 22伤害, +47%伤害, 穿透)

**霰弹枪 (Shotgun)**
- Lv1: 基础散射 (5投射物, 10伤害)
- Lv2: 强化散射 (7投射物, 13伤害, +30%伤害)
- Lv3: 终极散射 (9投射物, 17伤害, +70%伤害, 减速)

**步枪 (Rifle)**
- Lv1: 基础连发 (1投射物, 8伤害, 350ms CD)
- Lv2: 快速连发 (2投射物, 10伤害, +25%伤害, 280ms CD)
- Lv3: 急速射击 (3投射物, 13伤害, +63%伤害, 210ms CD)

**火球术 (Fireball)**

**环绕物 (Orbit)**

## 商人系统详细设计

### 生成机制
- 每30秒生成一次
- 生成位置: 玩家周围5格
- 最多同时存在3个商人
- 商人持续60秒后消失

### 商品类别

**武器类 (40%)**
- 随机武器
- 价格: 50-200金币
- 品质: 普通/稀有/史诗

**属性类 (40%)**
- 伤害强化 (+20%)
- 攻速强化 (+15%)
- 生命强化 (+30 HP)
- 移速强化 (+20%)
- 回复强化 (+2 HP/s)
- 价格: 30-100金币

**天赋类 (20%)**
- 随机天赋
- 价格: 150-300金币

### Reroll机制
- 每次刷新消耗金币
- 首次刷新: 20金币
- 刷新次数增加，消耗递增
- 刷新3次后商品全部更换

### UI设计
- 商人面板底部弹出
- 3个商品槽位
- 每个商品显示图标、名称、价格
- 购买按钮 / Reroll按钮
- 金币余额显示

## 基础攻击系统

### 武器类型
1. **近战武器** (剑、斧等)
   - 攻击范围: 2.5格
   - 攻击方式: 前方扇形
   - 攻击间隔: 800ms

   - 攻击间隔: 600ms

3. **法杖** (法杖、魔导书等)
   - 攻击范围: 8格
   - 攻击方式: 追踪魔法弹
   - 攻击间隔: 1000ms
   - 伤害: 基础伤害 × 1.2

- 根据装备的武器类型自动切换
- 无装备时使用默认近战攻击

## 游戏流程

### 开始游戏
1. 输入玩家名称
2. 选择初始天赋 (3选1)
3. 进入游戏

### 局内循环
1. **移动**: WASD控制
2. **攻击**: 自动攻击最近敌人
3. **升级**: 获取经验升级，选择技能卡牌
4. **收集**: 拾取地面物品、装备、金币
5. **搜索**: 激活搜索点获取随机物品
6. **交易**: 与商人交易购买装备
7. **管理**: 打开背包整理装备
8. **撤离**: 到达提取点安全撤离

### 局外循环
1. 查看统计数据
2. 解锁天赋
3. 查看成就
4. 开始新游戏

## 已知问题与修复

### 问题1: stats未定义
**错误**: `stats is not defined`
**修复**: 在render()函数中添加 `const stats = gameState.playerStats;`

### 问题2: gameState字段缺失
**错误**: `Cannot read properties of undefined (reading 'length')`
**原因**: startGame()重新初始化gameState时缺少新字段
**修复**: 在startGame()中添加所有新字段:
- merchants: []
- lastMerchantTime: -999999
- rerollCount: 0
- inventoryOpen: false
- merchantsShown: false

## 开发经验总结

### 成功要素
1. **渐进式开发**: 每个版本专注一个功能
2. **数据驱动**: 配置与逻辑分离
3. **对象池**: 避免频繁GC
4. **视口裁剪**: 大幅提升性能
5. **事件驱动**: 减少UI轮询

### 踩坑记录
1. **gameState初始化**: 新增字段必须同步更新startGame()
2. **变量作用域**: stats等局部变量需在函数内定义
3. **localStorage限制**: 不能存储函数/复杂对象
4. **Canvas性能**: 避免每帧clearRect全清
5. **事件绑定**: 注意重复绑定问题

### 最佳实践
1. 使用对象池管理频繁创建销毁的对象
2. 配置数据外置，方便平衡性调整
3. UI更新采用事件驱动，避免每帧更新
4. 碰撞检测使用空间分割算法
5. 渲染按层排序，减少状态切换
