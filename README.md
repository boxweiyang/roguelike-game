# 深渊撤离区 - 割草 Roguelike

一款吸血鬼幸存者风格的Roguelike提取射击游戏，具有深度天赋树系统和成就任务系统。

## 🎮 游戏特色

### 核心玩法
- **自动攻击**: 角色自动释放技能对抗敌人
- **割草体验**: 大量敌人涌来，体验割草快感
- **装备系统**: 4个装备槽位，5种稀有度
- **提取机制**: 在限定时间内成功撤离

### 深度系统

#### 🌳 天赋树系统
- **4层40节点**: 从基础到终极天赋
- **层级解锁**: 需要前置天赋解锁条件
- **天赋点获取**: 基于游戏表现（时间/击杀/等级/提取）
- **永久增益**: 死亡后保留，持续强化

**天赋层级**:
1. **第1层-基础** (8个): 生命/攻击/防御/速度等
2. **第2层-专精** (12个): 近战/远程/魔法专精
3. **第3层-高级** (8个): 闪电反射/吸血/暴击等
4. **第4层-终极** (4个): 凤凰涅槃/时间扭曲等

#### 🏆 成就系统 (33个成就)
- **新手成就** (5个): 第一次击杀/升级/撤离等
- **战斗成就** (10个): 击杀里程碑/Boss战等
- **收集成就** (8个): 装备/金币/技能收集
- **挑战成就** (10个): 生存时间/等级/完美通关

**奖励**: 每个成就提供3-100天赋点

#### 📋 任务系统

**每日任务** (每天刷新3个):
- 击杀50个敌人
- 到达10级
- 存活10分钟
- 收集5件装备
- 获得3个技能
- 获取500金币
- 开启3个宝箱
- 完成5次搜索

**每周任务** (每周刷新3个):
- 击杀500个敌人
- 成功提取5次
- 击杀3个Boss
- 单局到达30级
- 进行10局游戏

**奖励**: 金币 + 材料（普通/稀有/史诗）

## 🎯 操作说明

### 控制
- **WASD / 方向键**: 移动角色
- **自动攻击**: 技能自动释放
- **1/2/3**: 升级时选择卡牌

### 界面按钮
- **天赋树**: 查看/升级天赋
- **成就**: 查看成就进度
- **任务**: 查看/领取任务奖励

## 🚀 快速开始

1. 用浏览器打开 `index.html`
2. 点击"开始游戏"
3. WASD移动，自动攻击敌人
4. 升级时选择强化卡牌
5. 靠近物品自动拾取
6. 找到提取点成功撤离

## 💡 游戏技巧

1. **优先升级**: 先获得核心技能（旋风斩/闪电链）
2. **天赋树**: 死亡后投资天赋点解锁高级天赋
3. **成就导向**: 专注于解锁成就获得天赋点
4. **每日任务**: 每天完成任务获得额外奖励
5. **装备搭配**: 根据装备稀有度和词缀调整策略
